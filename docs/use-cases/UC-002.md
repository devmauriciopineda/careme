# UC-002 — Registrar la medición del día

## 1. Identificación

| Campo           | Valor                                              |
| --------------- | -------------------------------------------------- |
| ID              | UC-002                                             |
| Nombre          | Registrar la medición del día                      |
| Actor principal | Persona que hace seguimiento de su cuerpo          |
| Nivel           | Objetivo de usuario                                |
| Sistema         | Careme — aplicación de seguimiento corporal        |
| Prioridad       | Alta — sin registros no hay nada que mostrar       |
| Estado          | Implementado                                        |

## 2. Objetivo

Que el usuario deje constancia de su peso y de su circunferencia abdominal de un
día concreto, para que esa información pase a formar parte de su seguimiento
corporal.

## 3. Precondiciones

- El sistema está disponible.
- El usuario tiene acceso a la pantalla de seguimiento corporal (UC-001).
- No se exige que existan mediciones previas.

## 4. Disparador

El usuario confirma el formulario de registro.

## 5. Flujo principal

1. El usuario abre el formulario de registro en la pantalla de seguimiento.
2. El sistema presenta la fecha de hoy y campos para el peso y la circunferencia
   abdominal.
3. El usuario puede cambiar la fecha por otro día no futuro.
4. El usuario digita el peso y la circunferencia abdominal.
5. El usuario confirma el registro.
6. El sistema comprueba la fecha y ambos valores.
7. El sistema guarda la medición: si ese día no tenía registro, lo crea; si ya
   tenía uno, reemplaza sus valores.
8. El sistema confirma que el registro quedó guardado y actualiza de inmediato la
   tendencia y el detalle por fecha.
9. **Resultado:** el usuario ve su medición incorporada al seguimiento corporal.

## 6. Flujos alternos y excepciones

| Código | Situación                                                      | Respuesta del sistema                                                                                 |
| ------ | -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| A1     | La fecha elegida ya tiene una medición                          | El sistema reemplaza los valores de ese día e informa de que el registro quedó actualizado, sin duplicarlo. |
| A2     | El usuario cambia la fecha seleccionada                         | El sistema vuelve a comprobar que la fecha no sea futura antes de guardar.                             |
| A3     | El usuario no modifica la fecha                                 | El sistema registra la medición con la fecha de hoy.                                                   |
| E1     | Falta el peso, la circunferencia o ambos                        | El sistema señala los campos que faltan y no guarda nada.                                              |
| E2     | Un valor no es numérico, no es positivo, supera el límite permitido o tiene más de un decimal | El sistema señala el valor inválido indicando por qué y no guarda nada. |
| E3     | La fecha elegida es futura                                      | El sistema impide elegirla y no guarda nada.                                                           |
| E4     | El sistema no puede guardar la medición                         | El sistema informa del fallo en el idioma del usuario, conserva lo digitado y ofrece reintentar.        |

## 7. Postcondiciones

- **Éxito:** existe una sola medición para la fecha indicada, con el peso y la
  circunferencia abdominal ingresados; el seguimiento la refleja de inmediato.
- **A1:** la medición de ese día quedó actualizada con los nuevos valores; no se
  creó una segunda medición.
- **Fallo (E1, E2, E3):** no se guarda ninguna medición; el usuario corrige lo
  señalado y puede volver a confirmar.
- **Fallo (E4):** no se guarda ninguna medición; se ofrece reintentar.

## 8. Reglas de negocio

Reglas transversales aplicables —
[`reglas-de-negocio.md`](./reglas-de-negocio.md): RN-009, RN-019.

Reglas propias de este caso de uso:

- Toda medición tiene una fecha, un peso en kilogramos y una circunferencia
  abdominal en centímetros; ambos valores son obligatorios, positivos y se
  expresan con un decimal.
- El peso no puede superar 500 kilogramos y la circunferencia abdominal no puede
  superar 400 centímetros.
- La fecha del registro no puede ser futura.
- Se admite como máximo una medición por día: registrar de nuevo un día ya
  registrado reemplaza sus valores en lugar de duplicarlos.
- El registro guardado se ordena y se presenta del más antiguo al más reciente,
  igual que el resto de las mediciones.

## 9. Requisitos no funcionales relevantes

- **Validación comprensible:** cuando un dato no es aceptable, el usuario recibe
  un mensaje claro en su idioma, que explica qué corregir y no menciona
  detalles internos.
- **Consistencia temporal:** la fecha de la medición se interpreta como un día
  del calendario y debe guardarse y mostrarse igual independientemente de dónde
  se encuentre el usuario; no puede desplazarse por su ubicación geográfica.
- **Actualización inmediata:** al confirmar el registro, la tendencia y el
  detalle por fecha reflejan la medición sin que el usuario tenga que recargar
  ni repetir la acción.
- **Repetición segura:** si el usuario confirma dos veces seguidas, no se crean
  mediciones duplicadas para el mismo día.
- **Accesibilidad:** todos los controles del formulario son alcanzables y
  utilizables con el teclado, cada campo tiene su etiqueta asociada y los
  errores se anuncian sin depender solo del color.
- **Idioma:** los textos visibles para el usuario están en español.
- **Resiliencia:** ante un fallo al guardar, el usuario recibe un mensaje
  comprensible, no pierde lo que digitó y puede volver a intentarlo.

## 10. Fuera de alcance

- Editar o borrar una medición existente como acción independiente (el
  reemplazo ocurre únicamente al registrar la misma fecha).
- Registrar más de una medición por día.
- Una pantalla o vista nueva dedicada al registro (se usa la pantalla de
  seguimiento existente).
- Identificar al usuario o restringir el acceso.
- Distinguir mediciones de distintas personas.
- Notificaciones, objetivos o recomendaciones.
